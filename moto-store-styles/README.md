# VOLTGO — style concepts

Четыре визуальных направления для интернет-магазина мини электромото (детский сегмент).

## Как смотреть

Открой `index.html` в браузере, затем любой из вариантов:

| Файл | Настроение | Палитра | Шрифты |
|------|------------|---------|--------|
| `01-pitstop.html` | Race day / асфальт | чёрный + safety yellow | Bebas Neue + DM Sans |
| `02-trail.html` | Outdoor / дача | лес + teal + clay | Fraunces + Outfit |
| `03-candy.html` | Toy garage / подарок | cherry + cobalt | Racing Sans One + Space Grotesk |
| `04-softvolt.html` | Parent trust / soft tech | graphite + mint | Sora + DM Sans |

Фейковый бренд: **VOLTGO**. Это только hero-концепты первого экрана.
